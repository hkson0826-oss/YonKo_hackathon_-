근거: [운영 규칙](operation_rule.md) 4절. 보고서에는 모델 정보, 입력 프롬프트, 사용 목적·범위를 기재해야 한다.

## 사용 도구 및 모델

- 도구: Codex 데스크톱 앱.
- 모델 정보: 대화의 에이전트 안내상 GPT-6 기반 Codex. 정확한 선택 모델의 세부 식별자와 버전은 이 기록에서 확인하지 못했다. **보고서 제출 전에 앱의 실제 모델 표시를 확인해 보완해야 한다.**
- 사용일: 2026-09-27 KST.
- 이 파일은 현재 대화의 사용자 입력과 수행 내역을 소급 정리한 기록이다. 내부 추론이나 공개되지 않은 시스템 프롬프트를 기록한 것이 아니다.

## 사용자 프롬프트

아래는 이 대화에서 확인되는 입력이다. HTML 공백 표현과 링크 표시만 읽기 쉬운 형태로 정리했으며 원문의 오타는 유지했다.

### P-001 — 규칙 분석과 외부 레퍼런스 조사

```text
자 해당 게임 규칙을 파악할거야.

근데,

docs 에 있는 것들 / rule 이해가 안되면 rule image 그리고 instructure , 그리고 cpp/ python 예시 코드까지 읽고

1. 비슷한 해커톤(비슷한 알고리즘 밑 로직을 활용할 수 있는) 수상 코드 찾아줘 -> 우리가 보고서에 reasoning만 잘 만들어서 쓰면, 좋은 전략으을 쉽게 만들 수 있어.  (바로 활용 가능하다거나, 너가 직접 빌드하는 것 보다 더 빨르고 정확해 보이는 것들만 가져와, 아니면 안가져 와도 괜찮아)
```

목적·범위: 로컬 규칙·예제 분석, 외부 공개 전략과 소스 조사, 적용 가능성과 이식 비용 비교. 결과: delineate의 목표 중복 비용 개념을 선택했고, 실행 가능한 우승 소스가 공개된 것으로 오인하지 않도록 구분했다.

### P-002 — 첫 전략 구현과 초기 테스트

```text
https://github.com/delineate/cg-2022-fall-challenge-strategy#movement

해당 레퍼런스 기반으로, 일단 전략 간단하게 짜보고, 나서 테스트 한번 돌려 볼까?

이거 테스트도 한번 해볼 수 있어서, 일단 rule참고해서, 저거 기반으로 전략 한번 짜줘.

그 다음에 내가 테스트 결과 알려줄게, 그러고 나서 더 고도화 해봐.
```

목적·범위: LLM이 Python 전략 코드, 테스트 스크립트, 전략 설명을 작성했다. 제공 스타터의 입출력 모듈은 복사해 사용했다. LLM이 로컬 도구로 8경기와 프로세스 출력 비교를 실행하고 제출 ZIP을 생성했다. 사용자가 직접 코드를 작성·검증한 것으로 기술하지 않는다. 결과와 검증 한계는 [개발 기록](development_log.md)의 EXP-001 및 ENV-001에 정리했다.

### P-003 — Windows 로컬 대전 가능 여부

```text
이거 test result는 공식 엔진 호출 방식을 토앻서 window 에서도 할 수 있는거야?
그러면, 내가 만약에 local 환경에서도 내 친구 agent랑 vs 로 test 해볼 수 있는 거야? (내 친구도 yonsei 기준에서 만들긴 했어)
```

목적·범위: 함수 직접 호출 대전과 별도 프로세스 대전의 차이, Y/K 진영 처리 조건 설명. 이 단계에서는 친구 코드 수령·대전을 수행하지 않았다. 이후 LLM이 친구를 다른 참가 팀으로 오해해 공유 금지 안내를 했으나, P-005에서 같은 팀원임이 확인되어 그 안내를 정정했다.

### P-004 — 보고서용 개발 로그 보존

```text
operation_rule 읽어보면, 개발 log 까지 저장하는게 좋다고 하거든?
그래서 보고서 용 log까지 만들어서 저장해줘.
```

목적·범위: 운영 규칙 확인, 이전 작업의 설계 이유와 측정 결과 문서화, 프롬프트 기록, 초기 코드·실험 증거 스냅샷과 해시 보존. 전략 변경이나 추가 성능 실험은 하지 않았다.

### P-005 — 같은 팀원임을 명확히 설명

```text
(내말은 나랑, 내 친구 우리 같은 팀원끼리 공유하는거 말한거였어)
```

반영: 팀 내부 공유와 로컬 비교 테스트는 다른 참가 팀 간 공유 금지와 구분했다. 사용자 요청이 팀 간 공유에 해당한다는 이전 해석을 철회하고 개발 기록에 반영했다.
