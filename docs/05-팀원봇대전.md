## 드러난 사례

[시드 1000/Y](../records/replays/teammate-hk-v1/seed-1000-Y.json)는 141턴에 우리 0점, 팀원 35점으로 패했다. 20턴 W 수는 우리 61명·팀원 71명, 80턴에는 146명·261명으로 벌어졌다. 이는 해당 경기에서 장기 병력 격차가 커졌다는 관찰이다. 어떤 생산·이동 판단이 원인인지는 추가 분석이 필요하다.

시드 1017에서는 우리가 Y일 때 26:3 승리, K일 때 2:27 패배했다. 앞선 자체 공격형 상대에서는 같은 맵 양 진영 모두 패했다. 동일 맵도 상대 정책과 진영에 따라 결과가 달라지므로 맵 하나의 성적이나 한 상대의 승률만으로 개선판을 채택하지 않는다.

팀원 봇은 현재 v1을 실제로 이기는 고정 평가 상대에 추가한다. 이 40경기의 성적은 해당 맵·상대에 대한 결과이며, 실제 참가자 전체나 서버 상급과의 보편적인 순위를 뜻하지 않는다.

## 재실행

현재 프로젝트 루트에서 다음 명령을 실행한다. 원본 팀원 ZIP도 `main`에 포함되어 있으므로 별도 worktree 없이 재현할 수 있다. 같은 경로로 재실행하면 로컬 결과와 리플레이를 갱신하므로 새 실험에는 출력 경로를 바꾼다.

```bash
python3 -m zipfile -e submissions/delineate-v1.zip artifacts/opponents/delineate-v1
g++ -std=c++20 -O2 submissions/first/main.cpp -o artifacts/first_bot
python3 tests/benchmark.py \
  --candidate './artifacts/first_bot' \
  --opponent 'python3 artifacts/opponents/delineate-v1/main.py' \
  --start 1000 --seeds 20 \
  --save-losses records/replays/teammate-hk-v1 \
  --output records/benchmarks/teammate-v1/benchmark-teammate-hk-v1.json
```

벤치마크 도구에 상대 봇의 최대 응답 시간 기록도 추가했다. 이후 팀원 브랜치가 갱신되더라도 이번 worktree와 결과는 위 커밋을 기준으로 유지한다.
