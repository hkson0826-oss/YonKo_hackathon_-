# 9월 30일 재검증: v8 유지

**새 후보 guard4는 기각하고, 검증된 guard3(사이트 v8)를 유지하도록 권고한다.** 새 6개 맵의 96경기를 완료했으며, 독립 선택 배치에서는 양 진영 모두 기존 v8보다 3승씩 줄었다. 새 제출 파일을 만들거나 사이트의 선택 코드를 바꾸지 않았다.

기준선·후보·상대 4종의 소스와 바이너리를 동결하고 같은 맵에서 양 진영을 바꿔 비교했다. 선택 단계의 사전 조건인 Y 개선을 통과하지 못해 최종 10맵 평가와 GCC12 제출 포장은 실행하지 않았다. 작은 고정 상대 표본이므로 실전 승률이나 리더보드 점수로 환산하지 않는다. [판정과 수치](../records/recovery/20260930/decision.json).

## 수정 가설과 기각 근거

이전 기록에서는 기존 행동으로 경제 거점에 W4~6이 합류하는데 방어 함수가 W1을 추가로 남기는 장면이 있었다. guard4는 기존 행동의 도착 W가 3 이상이고 즉시 적 W 위협이 없으면 추가 예약을 생략했다. 다른 예약 두 개로 W2가 빠져도 최소 W1은 남도록 제한했다. F 호위 보호와 150턴 이후 종료 조건은 유지했다.

기록된 두 장면의 첫 행동 차이는 제거했고, 경계·생산·이동·순간이동·호위 검사 25개와 공식 엔진의 과거 기록 32전이를 통과했다. 그러나 국소적으로 낭비처럼 보이는 병력을 풀어 주는 것과 전체 경기 개선은 달랐다.

새 개발 패배 `16001/Y/v3`의 첫 차이는 13턴이다. ENG(3,7)에 기존 행동상 W5가 도착하지만, guard4가 오른쪽으로 W3을 보내는 대신 guard3는 W2만 보냈다. 같은 상태와 실제 행동에 기존 방어 함수만 적용해 이 차이를 재현했다. 반대로 승리한 대칭 경기에서는 도착 W3 조건이 이득의 첫 분기였다. 따라서 생략 문턱을 W4로 높이면 확인한 패배는 남고 확인한 개선을 없앨 수 있어 채택하지 않았다. 첫 분기의 재현은 전체 승패의 단독 원인 증명이 아니다. 다른 개선 경기의 최초 차이는 F 이동이어서 W만 수정한 방어 함수의 직접 효과로 볼 수 없다.
