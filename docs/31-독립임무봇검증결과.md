## 최신 공식 상대·규칙

10월 1일 03:47경 Chrome 대시보드에서 **현재 서버 선택이 v9 `v9_2.zip`**이며 업로드 시각이 03:25인 것을 새로 확인했다. 이 작업에서 업로드하거나 선택한 것이 아니다. 앞선 02:52 조회의 v8은 당시 상태이고, 이 문서의 v8은 로컬 고정 비교 기준선이다. 서버 v9 ZIP을 내려받아 해시를 검증하지 않았으므로 저장소 `submissions/v9_2`와 같은 바이트라고 단정하지 않는다. 현재 선택 v9는 유지한다.

[v4 연구용 ZIP](../artifacts/mission-scheduler-v4-20261001.zip)은 4파일·12,471바이트, SHA-256 `351cb2246f3a9b7dee240e032e55b62cf298c08f1dbe608b1864dacd14325e14`다. 실제 ZIP을 풀어 GCC12.2로 빌드하고 SDK smoke 1경기와 별도 2맵 양 진영 CPU 4경기를 검사했다. 3승 1패·오류/몰수 0, 578턴 명령 감사 이상 0, 후보 최대 응답 6.71ms였다. 서버 최악 시간을 보장하지 않는다. v3·v4 ZIP 각각 smoke 1+CPU 4경기, 합계 10경기의 실행 검증은 아래 리그 696경기에 합산하지 않았다. [패키지 검증](../records/submissions/mission-v4-20261001/validation.json), [ZIP 검사](../records/submissions/mission-v4-20261001/zip-inspection.json).

## 선택·최종 결과와 결정

개발 대전·v4 ZIP 증거는 `4b51044db365bfe1b3f438dddf6ae06dfffa67ff`에 보존했다. 선택 계획은 결과를 보기 전 `89cb89296148b8f2f83f9c95e14078dc8ff2da18`에서 v3·v4 동시 비교로 개정했다. 선택부터 최종까지 코드·ZIP을 고정했고 결과에 맞춰 다시 튜닝하지 않았다. [사전 선택 계획](https://github.com/hkson0826-oss/YonKo_hackathon_-/blob/89cb89296148b8f2f83f9c95e14078dc8ff2da18/records/research/new-bot-20261001/selection-plan.json).

선택용 19100–19107의 8맵에서 공통 192경기·직접 32경기를 완료했다. 공통 64경기씩 v4 49승·v3 46승·v8 45승, v8 직접전 16경기씩 v4 12승·v3 9승이었다. v4는 공통 Y 27/32·K 22/32로 v8보다 각 2승 앞서 사전 기준에 따라 **임무 계열 대표**가 됐다. [선택 공통](../records/benchmarks/mission-20261001/v4/runs/selection-common/summary.json), [선택 직접](../records/benchmarks/mission-20261001/v4/runs/selection-direct/summary.json).

미사용 최종 19200–19207의 8맵에서 고정 v4/v8과 공통 상대 4개·양 진영 128경기, v4 대 v8 직접 16경기, **최종 144경기를 모두 완료**했다. `v9_2`는 고정 정책 난수로 공통 상대에 포함했다.

|---|---:|---:|

| 등록 Y 32경기 | 19승 13패 | 22승 10패 |
| K 32경기 | 21승 11패 | 21승 11패 |

최종 직접전은 v4 **9승 7패**로 직접전 기준을 통과했다. 그러나 공통 전체·등록 Y 성적이 기준선보다 낮고 j_balanced 승점률 차이가 −0.375로 허용 회귀 한도 −0.25를 넘었다. 따라서 **최종 채택 심사는 실패, 연구 후보로만 보존**한다. 선택 맵의 우위나 직접전 승리를 일반적인 성능 향상으로 해석하지 않는다. 최종도 8맵뿐이고 시간 제한 상대의 실행 변동이 있어 더 넓은 상대·맵 분포의 우열을 확정하지 않는다. [최종 공통](../records/benchmarks/mission-20261001/v4/runs/final-common/summary.json), [최종 직접](../records/benchmarks/mission-20261001/v4/runs/final-direct/summary.json).
