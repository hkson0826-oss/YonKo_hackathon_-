# v3의 세 패배와 종반 F 생산 반례

동일 맵·진영·공통 상대에서 v3와 v8을 비교했다. 전체 리플레이는 분석 자료이며, 반사실 입력은 공식 serialize_turn의 합법 관측만 사용했다. 세 경기 선택은 결과를 본 뒤의 개발 진단이다.

- seed19012 Y/r3: v3는 43턴 0:32 패배, v8은 103턴 34:0 승리였다. v3는 T13에 상대의 병원 두 곳 소유를 허용하고 T14 ENG 중립화, T15 상실을 겪었다. 병원 선점과 경제 침입이 얽혀 있어 단일 수정으로 검증하지 않았다.
- seed19011 Y/s3: v3는 160턴 4:37 패배, v8은 36:5 승리였다. T20 W81:83으로 비슷했지만 v3는 T80 W48:129로 벌어졌다. 초기 HALL 상실, 이후 병력 교환과 이동이 함께 작용하며 특정 자동 수정을 증명하지 않았다.
- seed19010 K/j_balanced: v3는 160턴 15:20 패배, v8은 123턴 33:0 승리였다. v3는 T156 F4로 전체 수 목표를 채웠지만, 병원에서 새 F를 생산하면 중앙 WATCH를 종료 전에 중립화·점령할 수 있었다.

세 경기 체크포인트와 원본 해시는 `three_loss_comparisons.json`에 있다. 종반 반사실은 `final_flag_counterfactual.py/json`, 합법 입력은 `turn156-K-legal-input.txt`다.

반사실은 원본 T1–155 상태를 SDK로 복원하고 매 턴 units/resources/buildings 일치를 확인한 뒤 T156–160의 상대 명령을 고정한다. 새 F는 병원(12,8)→(11,8)→(10,8)→(9,8)→WATCH(9,9)로 이동한다. W 생산은 T156 6→4, T160 6→5로 줄이고, 부족한 W2의 후속 이동 세 줄도 줄여 양측 명령 수량·비용 검사를 통과했다. 원본 20:15(Y:K) 패배가 16:19 승리로 바뀌었다. 이는 실행 가능한 행동의 증거이며, 미래 적 반응이나 v4 실제 정책 효과를 증명하지 않는다.

`source-v3`는 후보 SHA256 `5cff84e533234f02fa8665de009ec7b2d10641c5baf5a33ac3fcc7edddb434e1`을 보존한다. 이 진단에서는 후보를 변경하지 않았다. 이후 승인된 v4와 독립 검사·새 대전은 별도 작업 단위다.
