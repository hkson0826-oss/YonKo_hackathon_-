# v3 추가 감사: 후보 채택 기각

**이 실험의 완료 결론은 기존 v3 유지다.** `f3_v2_warrior_reserve`는 앞선 holdout을 통과했지만, 사전 선언한 추가 감사에서 두 조건을 실패했다. 이 최초 실험에서 새 제출 ZIP은 만들지 않는다.

8700–8731의 새 32맵 × 동일 상대 8종 × 양 진영 × 후보/v3, 총 **1,024경기**가 완료됐다. 초기 맵·상대·진영으로 직접 짝지어 원본 결과를 재집계했고 일정 누락·중복, 오류·몰수는 0이었다. 첫 후보 잠금 및 소스는 이전 holdout과 같았다. 게임 승점률이며 공식 리더보드 보정 점수는 아니다.

**실패한 두 게이트**: 고정 6종 Y 비회귀(실제 −1.0417pp), 상대별 Y 회귀 12.5pp 이내(`j_v2_reclaim_relay`에서 −25pp). 전체 Y +0.78125pp와 추가군 Y +6.25pp가 이 실패를 상쇄하지 않는다. 나머지 네 조건은 통과했다.

추가 감사는 앞선 80맵 holdout의 대체가 아니라 별도 통과 조건이다. 이전 후순위 후보의 좋은 성적을 이 실행의 대체 추천으로 사용하지 않는다. 별도의 새 확인 계획이 실행되더라도 이 기록과 `recommended: v3`는 그대로 보존한다.

실행은 컴파일 후 프로세스별 **402,653,184바이트(384MiB) RLIMIT_AS**를 적용했다. RSS/cgroup 제한이나 공식 제출 컨테이너와 동일한 재현은 아니다. 원격 TMP는 회수 후 삭제됐으며 [회수 기록](transport_receipt.json)에 남아 있다.
