# 경기 원본 확보 현황

2026-09-28 후속 확인. 사용자가 **리플레이 파일 다운로드 때 Chrome에 ‘조직에서 차단됨’이 표시된다**고 확인했다. 이전의 다운로드 미완료 기록에 대한 추가 근거다. 정책의 소유자·구체 설정은 확인하지 않았으며 변경하지 않았다.

- 사이트의 우리 공식 경기 목록: 19건.
- 확보·해시 검증한 원본: 18건, 상대 15팀, 1,978턴 전이.
- 누락 원본: 하면해전 `rolling-game-99740c430713d5754ed6861ceef5f2baae7fa19465c4fbd34e98077ea5a3adfb`.
- 해당 경기의 시작·종료 화면: 확보. 38턴 즉시승리·종료 공개 점수 43:0. [화면 관측](haemyeonhae-ui-observations.json)은 원본 JSON을 대신하지 않는다.
- 정상 다운로드 파일과 프로젝트·기존 임시 다운로드 산출물 경로를 대조했으나 누락 JSON은 찾지 못했다. `Downloads/replay.json`은 이미 확보된 신촌도 우리땅전과 같은 파일이었다.
- 기존 18개 원본의 해시·크기·경기 ID는 보존된 목록과 일치한다. 원본·제출 파일을 변경하지 않았다.

다운로드가 정책에 따라 허용된 뒤 정상 기능으로 남은 파일을 수집해야 한다. 다운로드 정책 변경, 차단 우회, 거부된 파일 복구, 차단된 원본을 다른 경로로 추출하는 작업은 하지 않았다. Chrome 프로필·쿠키·캐시·격리 영역도 조사하지 않았다.

따라서 **전체 원본 확보 완료 상태가 아니다.** 파일이 추가되면 경기 ID·진영·결과·턴수·해시를 확인하고 기존 분석을 덮지 않는 새 실행으로 19경기를 비교한다. 다른 팀끼리의 상세 경기나 미관측 상위 팀의 코드·행동 자료를 확보했다는 뜻도 아니다.
