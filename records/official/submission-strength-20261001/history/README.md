서버8 ZIP은 `15fe3b79…`, 서버11 ZIP은 `07689054…`로 다르지만, 직접 ZIP을 열어 **4개 파일의 이름·내용 SHA가 모두 같음**을 재확인했다. 공통 main.cpp SHA는 `61a4f25113d9bf2c387a59ddc770a3143de6311e3fd2e004827a66eb78edfbc9`다. 반면 서버9·10의 같은 파일명은 같은 내용임을 증명하지 않는다. 로컬 main v9_2도 초기/후기 `main.cpp` 해시는 같지만 `v9_strategy.hpp`가 다르므로 main.cpp 하나의 해시로 전체 전략을 식별하면 안 된다. v9-lock도 별도 후보다.
