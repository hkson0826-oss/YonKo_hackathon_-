# CPU·GPU 선택 조사

2026-09-27. 구성된 Firecrawl MCP의 개발 문서 검색을 먼저 사용하고 NVIDIA·Python·irace·SMAC 공식 문서를 직접 읽었다. 일반 블로그와 제3자 저장소는 판단 근거에서 제외했다.

- `sources.json`: URL, 확인 시각, 출처 종류, 근거와 적용 해석.
- `raw/*.json`: 출처별 검증한 짧은 원문 발췌와 수집 메타데이터. 전체 페이지의 사본은 아니다.
- [판단 문서](../../../docs/14-CPU와GPU선택근거.md): 코드·설정 후보 평가, CPU 전체 대전, GPU 배치 계산의 구분.

이번 조사는 새로운 학습 시스템 도입을 전제로 하지 않는다. 외부 문서의 성능 수치를 이 대회나 RTX 3090 8개의 처리량으로 옮겨 쓰지 않았다. 실제 파일럿 결과는 별도 측정 기록에서 관리한다.
